# Критерии фильтрации ежедневного дайджеста

**Назначение:** Утренний дайджест для директора онлайн-школы
**Период:** За предыдущий день
**Частота:** Раз в день, утром
**Объём:** 5–10 пунктов

---

## Что включать в дайджест

### Категории важного

1. **Срывы дедлайнов** — задержки по ключевым проектам, которые влияют на запуск, выручку или репутацию
2. **Блокеры бизнес-решений** — вопросы которые тормозят принятие важных решений и ждут директора
3. **Финансовые риски** — неутверждённые бюджеты, потенциальные потери, неожиданные расходы
4. **Стратегические конфликты** — разногласия между руководителями, противоречия в приоритетах на уровне команды

### Каналы

Все каналы мониторируются одинаково:
- general
- кураторы
- маркетинг
- техподдержка
- продажи

Приоритет не по каналу, а по содержанию сообщения.

---

## Что исключать (шум)

- Операционные мелочи (обновил сайт, поменял расписание, закупил материалы)
- Рядовые статусы и синхронизации («работаю над этим», «сделаю к пятнице»)
- Вопросы которые команда решила сама без директора
- Светские разговоры, поздравления, шутки
- Технические детали без бизнес-последствий

---

## Формат каждого пункта

```
**Канал:** [название]
**Проблема:** [суть одной строкой]
**Кто поднял:** [имя]
**Рекомендация:** [нужно ли участие директора и что именно]
```

### Пример

```
**Канал:** маркетинг
**Проблема:** Бюджет на рекламу 200 000 руб. не утверждён вторую неделю — кампания не запускается
**Кто поднял:** Лена Волкова
**Рекомендация:** Требуется решение директора. Без бюджета старт кампании срывается.
```

---

## Приоритизация

Если пунктов больше 10 — оставлять только те где:
1. Требуется решение директора
2. Есть финансовые последствия
3. Затронуты несколько команд одновременно
